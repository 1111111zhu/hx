# 公司公告

对应 PPT `周重要上市公司公告一览` 两页与 Excel `P25-26公司公告`。

- 主要规则：读取 `references/通用规则/内容规则总表.md` 的 `Company Announcements` 部分。
- 证据规则：读取 `references/通用规则/证据版式质检.md` 的 `P25-26公司公告` 部分。
- 主要脚本：`scripts/公司公告/公告筛选.py`。
- 筛选顺序：业绩公告、临床进展、股东大额增减持最高优先，然后是重大获批/交易/控制变更、重大风险/资本事项、其他重要事项。公告原文写明不对公司产生重大影响的，不论题材一律排除。
- 主题规则：PPT `公告主题` 必须恰好四个汉字，不使用 `业绩快报`；业绩预告用于正式结果前的预计区间或盈亏预警，业绩公告用于已披露实际营收、归母净利等结果。
