# 政府政策

对应 PPT `近期行业重要政策` 与 Excel `P22行业政策`。

- 主要规则：读取 `references/通用规则/内容规则总表.md` 的 `Industry Policy and Government Announcements` 部分。
- 证据规则：读取 `references/通用规则/证据版式质检.md` 的 `P22行业政策` 部分。
- 主要脚本：`scripts/政府政策/政策筛选.py`。
- 筛选顺序：全国制度改变、全国重要规范、重大单项决定；重要性优先于发布时间。
- 来源边界：只接受国家级政府部门或国家监管机构原文件/详情页，默认排除公开征求意见稿、意见征集和咨询稿。
- 展示规则：日期只写月日不写年份；`发文机构` 只写一个主办/排名第一机构；`主要内容` 使用最短完整官方原文事实句。
