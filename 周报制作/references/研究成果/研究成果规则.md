# 研究成果（Research Results）阶段规则

本文件是 `华鑫医药团队近期研究成果` 阶段与 worksheet 1 `Research Results` 的专属入口。

## 为什么单列此文件

此前研究成果阶段只有一句路由说明，没有专属规则，导致全量刷新时该节被跳过或直接沿用模板里的历史行——即用户反馈的"要把华鑫医药团队近期研究成果这里从医药新观里抓取并更新，但你漏了"。本文件把该阶段定为**不可跳过的强制阶段**，并给出可执行的抓取与校验流程。

## 强制刷新规则

1. **`all stages` 刷新时本阶段必须执行。** 不得以"其他阶段更紧急""模板里已有内容"为理由跳过。
2. **数据源只能是当次授权的 `医药新观` 导出**（WeWe-RSS / feed / 已归一化的 JSON/RSS/Atom 文件）。不得绕过反爬直接抓取微信历史页，不得用第三方转载、旧周内容或推测内容填充。
3. **不得沿用模板或上周的行。** 内置模板 `assets/templates/weekly-template.pptx` 属于历史版式基线，其研究成果内容是旧内容；把它当作已更新成果交付属于 `failed_validation`。
4. 授权源不可得时，本阶段标记 `blocked_source` 并在交付说明里明确写出，**不得**让模板旧行冒充已刷新内容。

## 执行流程

### 第一步：抓取并归一化候选

```bash
python3 scripts/研究成果/医药新观报告提取.py \
  --input <医药新观 feed URL 或本地导出文件> \
  --out <工作目录>/研究成果候选.json
```

可选参数：

- `--depth-limit N`：只保留前 N 条深度报告；`0`（默认）保留全部。
- `--comment-limit N`：只保留前 N 条点评报告；`0`（默认）保留全部。

脚本输出结构：

```json
{
  "深度报告": [{"title": "...", "url": "...", "published_at": "..."}],
  "点评报告": [{"title": "...", "url": "...", "published_at": "..."}]
}
```

运行脚本前先执行 `--help` 确认参数。

### 第二步：分类、去重、排序

- 只纳入 `深度报告` 与 `点评报告` 两类，其他栏目丢弃。
- 先按 `url` 去重，再按归一化标题去重（忽略空白与大小写差异）。
- 每类内按 `published_at` 倒序排列。
- 标题与日期**原样复制**，包括年份与实质性限定词，不得改写、缩写或补全。

### 第三步：按锚定周区间过滤

- 每条入选行的发布日期必须落在本次锚定周区间（由 `scripts/通用/周报预检.py` 按"上周六至本周五"确定，以该脚本结果为准）之内。
- 确需保留期外重要行时，必须逐条登记为 `retained_older_due_to_importance` 并写明理由。
- **无法回溯到当次导出、且未登记的旧行 = 过期行，必须删除。** 交付物里存在这类行即 `failed_validation`。

### 第四步：按已批准版式的容量与栏目配比填充

- 行数密度与 `深度报告`/`点评报告` 的配比，以**用户最新批准的 deck** 为准。
- 只有在已批准的 deck 明确显示 20 行密度时才能用 20 行；不得继承某个更旧工作副本里更小的容量。
- 在删除旧行之前先比对完整合格池，并记录 `added` / `removed` / `retained_older_due_to_importance` 三类清单。

### 第五步：重建表格并写入 worksheet 1

- 以原生可编辑表格重建研究成果网格，保持模板字体、字号、行高、对齐与配色。
- 把最终表格的完整渲染图插入 worksheet 1。
- 不覆盖源文件；在带日期的工作副本上操作。

## 交付前校验清单

| 检查 | 通过条件 | 不通过时 |
|---|---|---|
| 阶段已执行 | 本阶段在本次运行中真实抓取过 | `failed_validation`，不得标 `completed` |
| 来源合法 | 数据来自当次授权的 医药新观 导出 | `blocked_source`，明确上报 |
| 无过期行 | 每行的发布日期都在锚定周区间内，或已登记 `retained_older_due_to_importance` | 删除该行或补登理由 |
| 标题日期精确 | 与源导出逐字符一致，含年份 | 修正为源文本 |
| 表格可编辑 | worksheet 1 为原生可编辑表格，未扁平化为图片 | 重建 |
| 已记录增删 | `added`/`removed`/`retained_older_due_to_importance` 三类清单齐全 | 补齐 |

## 常见错误

- 全量刷新只做了行业新闻/公司公告，研究成果整节没碰——这是最常被投诉的一种。
- 把模板自带的历史行原样留下，然后在交付说明里写"研究成果已更新"。
- 用文章发布日替代报告发布日期。
- 只按文件名或抓取顺序排序，没有按发布日期倒序。
- 把表格渲染成图片导致不可编辑。
