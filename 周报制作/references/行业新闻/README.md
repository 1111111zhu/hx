# 行业新闻

对应 PPT `近期行业要闻梳理` 两页与 Excel `P23-24行业新闻`。

- 主要规则：读取 `references/通用规则/内容规则总表.md` 的 `Industry News` 部分。
- 证据规则：读取 `references/通用规则/证据版式质检.md` 的 `P23-24行业新闻` 部分。
- 主要脚本：`scripts/行业新闻/医药魔方新闻整理.py`、`scripts/行业新闻/微信证据截图裁剪.py`。
- 来源边界：只接受可核验的 `医药魔方Info` 原文，排除活动、会议、邀请、广告、培训、招聘等推广内容；不使用阅读量排序。PPT 正文删除所有括号及括号内文字，包括 `（以下简称……）`。
