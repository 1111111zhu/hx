# 公众号 API 架构

## 组成

```text
Word/PPT 文件
    ↓
Codex + 通用文章外发 Skill
    ↓
本机 API 适配脚本 scripts/wechat_draft_api.py
    ↓  HTTPS + AppID/AppSecret
微信官方公众号 API
    ↓
图片素材 / 公众号草稿
```

Skill 是流程和规则，不是账号凭证，也不是服务器。每个使用者必须使用自己的公众号授权配置。

## 需要的配置

- `WECHAT_OFFICIAL_APP_ID`
- `WECHAT_OFFICIAL_APP_SECRET`
- 调用 API 的本机或服务器出口公网 IP，加入公众号 API 白名单

只做“创建草稿”时，不需要把服务器回调 URL、Token 和消息加解密配置写入 Skill。只有接收用户消息、菜单事件或其他回调时才需要回调服务。

## 当前脚本支持的安全范围

- 获取 access token 并返回脱敏状态
- 上传封面缩略图
- 上传正文图片
- 创建公众号草稿

脚本明确不支持发布、群发、删除草稿、修改菜单和账号设置。

## 分发原则

- GitHub 只存代码、规则、示例配置和文档。
- `.env`、本地密钥、钥匙串数据、access token 和真实图片不提交。
- 使用者首次运行配置脚本，在自己的机器上输入自己的公众号凭证。
- 如果使用中央服务器，必须额外实现多租户隔离、每用户独立凭证、访问控制、日志脱敏、限流和撤销机制；本 Skill 默认不假设存在中央服务器。
