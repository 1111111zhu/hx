# 通用文章外发规则

## 输入

- 主要输入是一份华鑫证券研究报告 Word 文档。
- 可选输入是公众号封面/合规 PPT 模板。
- 文件名不能替代正文事实。股票代码、报告日期、报告标题、评级和分析师信息必须从 Word 实际内容核对。

## 首图

- 正文第一张图使用用户最新指定的公众号合规 PPT 模板生成合规首图截图，不使用研究报告第一页整页截图。
- 合规首图保留 PPT 模板的紫色品牌色、虚线/边框、标题位置和整体版式。
- 仅替换与本期报告有关的证券简称、代码、标题、对外发布日期、发布机构、分析师和 SAC 编号。
- 制作合规首图、免责声明、风险提示、团队介绍等固定素材时，优先从用户提供的 PPT 模板中搜索并复用对应页或对应文案。
- Word 首页左侧信息栏（评级、分析师邮箱、基本数据、市场表现、相关研究等）不整栏复制进公众号正文。
- Word 首页左侧信息栏只用于核对和提取标题、代码、日期、评级、分析师、SAC 编号等字段。

## 正文顺序

1. 正文标题
2. 作者/团队署名
3. PPT 合规首图
4. 事件
5. 投资要点
6. 盈利预测和投资评级
7. 风险提示
8. Word 表格截图
9. 医药组介绍、证券分析师承诺、证券投资评级说明、免责条款
10. PPT 免责声明/风险提示等合规素材截图
11. 尾部摘要卡：左侧公司/行业 logo，右侧投资要点摘要

## 正文处理

- 正文以原文复制粘贴为主，不重写成新闻稿。
- 从 Word 正文右侧主栏开始复制，起点通常是“事件”，后续复制“投资要点”“盈利预测”“风险提示”等正文内容。
- 不复制 Word 首页左侧栏的“买入(首次)”、分析师卡片、基本数据、市场表现图、相关研究等块。
- 为了方便复制到公众号编辑器，正文标题、作者、虚线分割线、紫色栏目标题（如“事件”“投资要点”）优先做成纯 HTML，不做成图片；只有复制进公众号后明显无法保持版式时，才改用栏目截图。
- 紫色栏目标题建议用居中的 inline-block/短宽元素实现，紫底白字、窄条居中、适当字间距；避免用整行表格导致公众号编辑器自动拉满成宽条。
- 正文字号参考既有公众号文章：正文约 14px，段落行距约 1.9；正文大标题约 20px；紫色栏目牌约 18px。
- 可以删除页眉、页脚、页码、重复标题、表格排版残留和无关的大型财务附表。
- “投资要点”标题上方不要加虚线分割线；若“事件”标题上方已有虚线，事件正文结束后直接接“投资要点”标题。
- 涉及表格的内容不要用 HTML 手工重画，统一用截图/PNG 图片插入，包括预测指标表、公司盈利预测表、股票投资评级说明表、行业投资评级说明表等。
- 表格截图优先来自 Word 的预览模式、打印预览或 Word 导出的 PDF/预览图，这样不会出现编辑状态里的蓝色小箭头、换行符、对象锚点等符号。
- 若从本地 HTML 复制到公众号时图片无法带入，保留图片所在位置，改为在公众号编辑器中手动插入对应 PNG；本地 HTML 中的 data URL 或 file URL 图片不保证能被微信编辑器接收。
- 通常保留“预测指标”小表；若原文包含“公司盈利预测（百万元）”、资产负债表、利润表、现金流量表、主要财务指标等大表，也按模板用截图方式保留，除非用户明确要求删掉。
- 文末合规部分优先复制 Word 原文样式和原文内容，如“医药组介绍”“证券分析师承诺”“证券投资评级说明”“免责条款”等；其中出现的表格仍按截图/PNG 插入。
- HTML 最后增加一张尾部摘要卡：左侧放公司 logo 或医药行业相关 logo/图形，右侧放投资要点摘要。
- 尾部摘要卡左侧素材优先使用用户提供的已有素材；若用户没有提供，再从公司官网、公开资料或用户给出的医药企业 logo 素材合集检索。用户给过的小红书素材入口包括：
  - `https://xhslink.cn/o/9K1OeiDzh9d`
  - `https://xhslink.cn/o/1BQEfuX8DPz`
  - `https://xhslink.cn/o/6F7K0z2cVVX`
- 尾部摘要卡右侧文字由“投资要点”各条小标题或每条开头第一句提炼并连接，通常用分号分隔，控制在公众号摘要 120 字以内，不新增原文没有的判断。
- 尾部摘要卡可以整体渲染为 PNG 放入 HTML 末尾，避免公众号复制时 logo、边框或左右布局丢失；若图片没有随 HTML 粘贴进公众号，应手动插入对应 PNG。
- 可以修复 Word 转换造成的多余空格、拆开的数字、异常断行和重复字符。
- 保留原文的比较关系、时间范围、单位、预测限定语和评级口径。
- 不新增原文没有的事实、数据、结论、来源或公司观点。
- 预测数据不得改写成已实现数据。

## 合规

- 保留原报告的风险提示和必要免责声明。
- 不改变“买入”“增持”“中性”“卖出”等投资评级。
- 文末保留“来源：华鑫证券研究所”和报告日期。
- 文章仅作研究信息分享，不构成对任何人的个性化投资建议。
- 若发布主体不是华鑫证券或未获得转载授权，发布前确认版权和转载权限。

## API 草稿

- 无 API 配置时，只输出本地素材和可复制正文。
- 有 API 配置时，先只读验证认证，再上传封面和正文图片。
- 用户确认后才能创建草稿；创建草稿与发布文章是两个动作。
- 本 Skill 不提供发布命令，不自动群发。
